# 见众生评论口吻

把评论写成一个普通用户读到某个局部后顺手输入的话，而不是缩短版的读后感。

## 判断标准

- 只接住原文中的一个具体东西：一个动作、一件物品、一句对话，或一个很小的相似经历。
- 评论必须和原文中的具体细节自然相接，让没参与创作的人一眼知道它在回应哪一处。优先直接复用那个名词或动作，让对应关系藏在正常说话里；可以用“那个”“这种”一类口语指代，但指向不能含糊。
- 让信息密度低一点。可以有“我一般就是”“然后就”“其实”“好像”“有时候”这类自然的口语冗余，不必把句子压到最漂亮。
- 说完事实或反应就停。不要解释这个反应说明了什么，不替作者总结，也不为评论安排升华或回扣。
- 默认不用句号收尾。问号、感叹号、语气词和“哈哈”只在确实像这个人会输入时出现，不要为了制造真人感刻意添加。
- 长短不整齐，可以只有几个字。每篇手记安排 0–3 条示例回应，数量打散，允许没有评论。
- 不要求每条都善解人意。可以只是觉得好笑、想起自己、提出一个小问题，或补充一个无关紧要的细节。

## 需要避开的编辑腔

- 修辞性结尾：如“像没收到过”“仿佛把今天拱手让出去”。
- 提炼原理：如“数据不知道你在等谁”“边界不能外包给开关”。
- 工整对照：如“别人从背景变回人”“不是……而是……”。
- 生硬的回应提示：如“看到你说……”“你提到……”“关于你写的……”。不要宣布钩子，直接说与那个细节有关的话。
- 过度精确的书面副词：如“迅速”“确实”“反而”“原来”。日常语境确实需要时可以使用，但不要拿它们替句子收紧节奏。
- 为显得真实而堆错别字、网络梗或方言。真人感来自说话意图和松弛程度，不来自表演粗糙。

## 改写方法

先从原文圈出评论真正接住的词或细节，再删掉评论中的观点总结、比喻和漂亮结尾，只保留那件小事；然后用说话者平常会用的顺序补回必要连接词。最后把评论单独拿出来对照原文：如果对应不清楚，优先把原文里的名词或动作自然放进句子，而不是加上“看到你说”之类的引导；如果像一条值得截图转发的金句，通常还需要再松一点。

例如，看到有人说自己会划掉屏幕使用时间通知：

- 不写：`我每周都是看一眼，然后迅速划掉，像没收到过`
- 可以写：`我一般就是收到看一眼，然后就划掉了`

不要把这个例句当成固定句式；它说明的是语气，不是模板。
