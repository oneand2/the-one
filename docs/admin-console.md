# 网站运营后台

入口：`/admin`，也可从管理员个人中心的「进入运营后台」进入。沿用 `src/utils/vip.ts` 中的现有管理员账户；普通账户、未登录用户和未验证邮箱均不能访问后台数据。

## 已接入功能

- 运营总览：真实注册账户、有效会员、用户手记、待处理举报、近七日手记与评论数量、内容与交易记录数量。
- 用户管理：按邮箱、昵称、用户编号搜索，筛选有效会员或暂停发言的账户，分页查看；设置会员期限、暂停发言七天、恢复发言。
- 手记与评论：查询用户提交，按公开/隐藏/移除状态筛选；隐藏与恢复记录处理人、时间、原因。
- 交易记录：支付宝、微信、Apple 分渠道分页查询；查看订单金额、状态、入账时间，Apple 显示正式或测试环境。
- 举报处理：查看举报快照、原因、补充说明，隐藏内容、保留并驳回举报、暂停发布者发言；复用既有举报处理接口，并补齐失败反馈。
- 今日见闻：搜索和编辑已入库的见闻，保留日期，校验标题、原文、正文段落和出处后保存。
- 每日新闻：统一导航接入现有 `/admin/news` 发布编辑页。
- 数据与权限：展示各数据源的实际连接结果及统计口径。

## 口径与边界

所有列表从现有 Supabase 表和 Auth 查询，不含模拟数据。注册账户包括尚未建立 `user_profiles` 的账户；缺少档案时铜币显示「—」，不会伪造默认余额。列表每页 25 条，统计使用精确总数；用户查询读取所有 Auth 分页后搜索，档案每批最多 100 个编号，避免网关网址长度限制。当前提供最多 100,000 个账户的全量搜索，超出会明确报错，需要升级服务端搜索方案。

近七日内容以北京时间划分自然日，包括后来隐藏和移除的提交。项目内置示例手记与示例评论不混入用户统计。新增与活跃支持近 7 天／30 天，均包含今天。新增以 Auth 账户创建时间统计；注册方式优先使用服务端 `signup_source`，其次为原始 provider，兼容旧用户名账户。之后绑定的身份不改变原始注册方式；未知方式明确显示「未记录」。不收集广告、外部推广来源。

活跃统计来自 `user_daily_activity`，每个账户每天一条，期间人数再次去重。网页记录已登录的前台访问和交互；不靠空闲页面定时刷新制造活跃。App 通过现有会话检查、用户资料、聊天和起卦接口采集已验证身份的访问，不需要更新客户端；未接入的离线功能不计入。服务端生成日期与时间，不接收客户端指定的用户或计数。最早真实记录保存在 `user_activity_coverage`，之前日期显示「未采集」，首日和当天为部分数据。历史最近登录时间独立作为登录用户统计，不能还原历史每日活跃。最近活跃时间只展示选定期间的已采集记录。数据读取失败显示错误或「—」，不记作零。

交易数量包含各状态订单。Apple 记录包含测试环境，数据库没有保存实付金额，也没有完整反映后续退款，故不计算 Apple 收入；后台不执行扣款、退款或手动修改支付状态。

操作前有确认步骤。内容隐藏可恢复，用户暂停发言可解除。会员期限从操作时起重新计算并覆盖原到期日。见闻修改立即更新该日期的公开内容；新增整周见闻和配图仍沿用现有发布流程。活动、通知模板等尚不存在的业务未增加空壳入口。

## 配置与校验

沿用现有 `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_ANON_KEY`、`SUPABASE_SERVICE_ROLE_KEY`。管理员密钥只在服务端使用。生产环境 `NEXT_PUBLIC_SITE_URL` 应配置规范的 HTTPS 站点地址，以便反向代理下正确验证写请求来源。

本次新增迁移 `supabase/migrations/20260916080151_user_activity_analytics.sql`，需先应用再发布代码。两张采集表开启 RLS，撤销匿名与普通用户权限，仅服务端可读写；采集函数仅允许 service_role 调用，采用 SECURITY INVOKER 与固定 search_path。安全检查器关于「RLS 已开启但无策略」的提示在这两张表上属于刻意禁止浏览器直接访问，不能补公开策略。后台页面服务端验证身份，接口再次独立验证，返回数据禁止缓存。写接口按允许的实体、动作和字段执行，禁止通过额外 JSON 字段修改铜币余额或订单状态。

验证命令：

```sh
node --import tsx --test tests/admin-console.test.ts tests/admin-analytics.test.ts
node --import tsx scripts/check-admin-data.ts
npx tsc --noEmit
npm run build
```

`check-admin-data.ts` 是只读联网校验，使用本机 `.env.local`，仅输出数量与结果，不输出用户资料、密钥或支付凭据。自动测试覆盖身份限制、跨站请求、分页与搜索、读取失败、隐藏/恢复、会员更新字段与见闻校验。写操作使用隔离测试替身验证，不拿线上用户或订单做破坏性测试。上线后的管理员登录和真实运营操作仍应由管理员在实际账户中验收。

新增统计测试覆盖北京时间边界、跨日去重、来源归类、未来记录排除、未采集与读取失败、分页完整性。数据库去重验证在事务中执行并回滚，不保留测试活跃记录。
