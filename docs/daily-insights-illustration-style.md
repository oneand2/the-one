# 今日见闻矢量插画规范

这套规范用于「见天地 · 今日见闻」题头图。目标是让每篇内容都有自己的视觉线索，同时保持无印良品式的新中式极简气质。

## 核心气质

- 像印在温润宣纸上的现代版画：安静、克制、有呼吸感。
- 插画负责提出一个记忆点，不复述整篇文章，也不做写实场景堆砌。
- 插画根据内涵题名、经典原文与译文共同创作。栏目每天一则，不设内容类目。
- 优先提取正文中最反常识或最具画面感的事实，再把它转译成一个主体和一个必要的辅助意象。
- 不在插画内放品牌 Logo、类目文字、标题或装饰性印章。
- 主体与主要次景必须来自正文；允许少量纯气氛装饰，但它们只能帮助构图、空间或情绪，不能被误读成新的叙事对象。

## 固定画布与色彩

- SVG `viewBox`：`0 0 360 136`。
- 纸色：`#F2F0E8`、`#F3F1E9`、`#F4F1E8`。
- 墨线：`#526254`、`#56645A`，通常使用 `0.28–0.70` 透明度。
- 玉灰：`#CDD6CC`、`#9AAB9B`、`#71857E`。
- 土色：`#B79D80`、`#9C866B`。
- 朱砂：`#B66D5C`、`#A86456`，只作小面积焦点。
- 线宽以 `0.9–1.25` 为主；生物主体最多使用 `2.25`，所有端点保持圆润。

## 构图规则

- 保留至少三分之一空白，主体不超过画面高度的三分之二。
- 使用一处非对称焦点；不使用居中的图标式构图。
- 画面遵循约 `70 / 20 / 10` 的层级：主体占七成注意力，次景占两成，朱砂或小圆点等点睛元素不超过一成。
- 背景以纸色为主，可使用一层低透明度纸影、水纹、气泡或天象营造呼吸感；同一张图最多保留两类装饰元素，不使用渐变和重阴影。
- 卡片由外层浅灰纸框、内层暖白纸面和插画内框组成，圆角保持同心。
- 动画只作用于整张卡片的透明度与位移，SVG 内部保持静止。

## 内容匹配方法

1. 从标题和正文中选出一个核心事实。
2. 用一个主体表现事实，用一个次要符号交代语境。
3. 检查主体、次景、点睛三层是否清楚；装饰不得比主体更醒目，也不得让人误以为它是文章信息。
4. 保留足够留白，避免因为“有意义”就把所有信息都画进去。
5. 用共同色板和发丝线统一风格，不使用通用模板图。
6. 每则必须配置专属插画，文件名为 `public/daily-insights/YYYY-MM-DD.svg`。

## 旧版专属插画存档

- 「一家四姓」：同一屋檐下悬挂四张各不相同的姓名笺，表现一家人并不共享姓氏。
- 「两段觉」：左右两段床榻，中间留出一盏醒着的夜灯，表现第一觉与第二觉之间的清醒期。
- 「八条腕」：八条腕分别向不同方向舒展，表现腕部神经节的相对自主性。
- 「一月」：空置的心理诊疗室、月份页与休假行李，表现分析师一月集体休假。
- 「爸爸日」：带儿童座椅的自行车，表现父亲固定留出一天照顾孩子。
- 「二十七个月」：搁置的官帽与二十七个日历点，表现丁忧期间离职服丧。
- 「百岁观场」：手杖、灯笼与乡试号舍，表现百岁考生由曾孙提灯入场。
- 「日出在西」：金星、反向箭头与西侧日出，表现逆向自转。
- 「四百岁」：眼中带同心年轮的格陵兰鲨，表现以眼球晶状体定年。

自 2026-08-27 起，插画随周稿逐日配置，文件名不再包含「地、时、物」。
