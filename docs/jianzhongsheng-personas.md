# 见众生人物档案

这份档案用于保持示例手记中的人物连续性。人物均为虚构，不对应现实中的具体个人。新增手记前应先阅读本文件与 `src/content/jianzhongsheng.ts`，避免事实冲突、口吻趋同或重复近期主题。

## 既有人物

### 周五再说

- 生活轮廓：二十多岁至三十岁之间的城市上班族，独居或合租过，经历过离职和多次搬家，经常晚睡。
- 已发生的事：深夜清理手机照片，发现照片还清楚，自己却已从许多往事中退场；保留了一张拍坏的黑窗照片。后来收到每周屏幕使用时间报告，开始怀疑“亮屏七小时”是否都能被归为浪费，也意识到自己深夜不放下手机，有时是不愿让一天正式结束。
- 说话方式：第一人称随笔，句子不刻意漂亮；从手机、外卖、租房等日常物件进入记忆问题，带一点自嘲。
- 可延续线索：睡眠、旧同事、数字生活、独居习惯、离职后的变化。不要每次都写“遗忘”。

### 奶盖半糖

- 生活轮廓：有一个还在上小学或幼儿园的女儿，母亲住在另一处；处于同时照顾上一代和下一代的阶段。
- 已发生的事：曾嫌母亲语音太长，后来发现自己教女儿时也会反复说同一句话，开始完整听完母亲的语音。
- 说话方式：口语自然，常复述家人对话；思考藏在家务和亲子细节里，不使用艰深概念。
- 可延续线索：女儿成长、母亲衰老、家庭里的重复、代际误解、工作与照料的冲突。

### 郑大闲人

- 生活轮廓：退休的修车师傅，有成年儿子，仍住在熟悉的老社区。
- 已发生的事：退休后每天六点醒；舍不得扔旧工具；替楼下孩子修好自行车后重新感到自己“有用”。
- 说话方式：朴素、具体、克制，少用抽象词和长比喻；会承认道理自己都懂，但身体和习惯未必跟得上。
- 可延续线索：旧店、邻里、手艺的过时、和儿子的关系、退休后的时间。不要把他写成智慧老人或金句机器。

### 燕子v

- 生活轮廓：五十一岁，有一个成年或接近成年的女儿，仍在上班。
- 已发生的事：买了一件鲜红外套，没有听女儿换成灰色的建议；穿去上班后只得到门卫一句普通夸奖，吃面时还溅了汤。
- 说话方式：爽直、生活化，偶尔自嘲；会在意实用和他人目光，但正慢慢练习为自己作决定。
- 可延续线索：中年女性的身体、衣着、工作、夫妻或独处生活、与女儿角色倒置。不要把每次选择都写成励志胜利。

### 呱一下

- 生活轮廓：年轻上班族，做事认真但容易焦虑和过度控制，养花经验很差。
- 已发生的事：第三盆薄荷濒死；朋友指出不是没管而是管太多；第一次忍住不搜索“长新叶后该怎么办”。
- 说话方式：节奏稍快，擅长列举自己做过的补救动作；常在结尾留下一个很小、并不彻底的改变。
- 可延续线索：花草、做饭、等待消息、人际关系里的追问、工作中的完美主义。植物不必每篇都死。

### 土拨鼠打哈欠

- 已发生的事：毕业多年的学生感谢他曾说“你只是很累，不是一个差劲的人”；他不记得这句话，因此开始担心那些随口说出的伤人话；第二天仍在第三节课发了火。
- 说话方式：清醒、有职业细节，带干巴巴的幽默；不把自己写成完美教育者，也不轻易总结“教育的伟大”。
- 可延续线索：学生、同事、家长会、备课、职业倦怠、偶然影响。引用学生原话时保持自然。

- 说话方式：坦白但不过度煽情，警惕“顿悟后痊愈”的叙事；常写身体感受和具体食物。
- 可延续线索：吃饭、运动、镜子、他人的夸奖、身体与控制。不要提供医疗建议，也不要把恢复写成直线上升。

- 说话方式：直接、锋利，敢写不体面的念头；不急着原谅自己，也不靠自我贬低换取同情。
- 可延续线索：同龄比较、社交媒体、工作野心、友情、羞耻和竞争。不要让每篇都围绕嫉妒。

- 说话方式：像记录一件路上小事，前半段少解释；承认自己的善意常常来得太晚，不把自己摆在道德高处。
- 可延续线索：公交、菜市场、医院、排队、邻里和短暂相遇。不要让每个陌生人都负责提供感人反转。

### 方块七

- 说话方式：克制、略干，不掩饰价格和就业压力；允许比喻出现，但会立刻怀疑“这个比喻是不是太顺了”。
- 可延续线索：设备维修、办公室里的闭门会议、消费欲与安全感、生活中还能继续使用的旧东西。不要把节制消费写成道德优越。

## 标题与昵称

- 每篇示例手记须单独填写 `title`。按用户于 2026-10-22 确认的方向，用简洁、普通的日常标题，让读者一眼知道帖子在聊什么，或是在记录生活、吐槽、分享感受。多数 4–10 字，语意需要时可稍长，最多 24 字；不为整齐凑字数。
- 语气参照用户已认可的“最近手机用得有点多”“聊聊以前租的房子”“买了件新衣服”“朋友升职后的一点感受”“吐槽一下工作”“下班吃了碗面”“整理了一下相册”。这些是口气示例，不是批量套用的句式。“最近的一点感悟”“记一件小事”这类普通记录题目可以少量穿插。
- 标题只需点出话题或事情，不把经过、反转和结果压缩成两段长句，也不替每件小事提炼意义。避免散文题名、拟人、对仗、金句、热梗和刻意制造悬念；单独看不出话题的俏皮对白，如“你早说啊”“我就喜欢”“多放点辣”，也不作为默认方向。
- 整批标题要有自然的长短、词序和表达差异，不统一加“今天”“聊聊”“一点”“这件事”，也不全写成“我……了”。同一个人物的多篇内容应能区分，昵称与说话习惯保持连续。标题中的事实必须能在正文找到，不能添加正文没有的事故、情绪或结果；批量修改后逐篇核对正文，再通读标题列表检查重复句式。
- `title`、`authorId` 和 `excerpt` 各有用途：标题指向这一篇，昵称指向长期生活中的同一个人，摘要保留自然节选。不要用昵称代替标题，也不要照抄整段摘要作标题。已有真人手记可以没有标题，不替真人编造标题或改名。
- 昵称按普通社交网络的使用习惯写：长短、语言和格式自然混杂，可以是食物、动物、叠字、随口一句、英文或字母数字，也可以少量使用小名、姓氏称呼。允许“吨吨吨”“yuki_29”“方块七”“陈皮糖”同时存在；不要求每个名字漂亮、有寓意或体现人物性格。不要把所有人写成实名名册，也不要全员使用“某老师”“某阿姨”“某师傅”、诗意短句或同一款网络梗。
- 先独立确定昵称，再写人物这一篇发生的事。昵称可以和帖子、年龄、职业完全无关，不必替人物选一个“最合适”的身份标签；不要根据标题、职业、年龄或本篇物件反推昵称，不起“白衣服已阵亡”“门牌号写到一半”这类情节标签。参考公开社区时只学习命名形式，不搬用具体账号身份或假称真人投稿。
- 同一人物跨篇沿用同一 `authorId`。更名时同步示例回应里的 `authorId`、正文中明确引用该昵称的身份标签及本档案；保留手记和回应的 `id`，不借更名另建一个人物。网名不必等于现实称呼：家人、同事或学生对话中的“海燕姐”“宋老师”，以及刻章用的实名“林遥”，属于故事事实，不随网名更改。

## 每日续写规则

1. 每次新增 2–4 篇完整手记，直接追加到 `jianZhongShengSpace.entries`，不得覆盖或删除现有手记。
2. 每次至少有 1 篇来自上述既有人物，延续已经发生的生活，但不要机械复述档案；其余可使用既有人物或引入新人。
3. 新人若适合长期出现，须在本文件补充人物档案；一次性人物不必强行归档。
4. 同一天新增内容要在主题、年龄、生活处境和语言节奏上有明显差异。至少包含两种不同形态，例如：短札、叙事散文、带对话的记录、观念随笔、近乎流水账的日记。
5. 必须从具体经验、动作或物件出发。可以抵达哲学、历史、文学或技术，但不能先摆大道理再硬配生活案例。
6. 允许没有结论、允许轻松、允许无聊。不要每篇都伤感、反转、治愈或在最后制造金句。
7. 保留不整齐的真人感：犹豫、口头语、自嘲、偏见、自我推翻和没有解决的问题都可以存在。
8. `excerpt` 是 55–95 字的自然节选，不是营销标题；`body` 建议 180–520 字并使用自然分段；`id` 使用不重复的英文小写短语，可带日期；昵称允许自然的数字或字母组合，但不要为了区分批量人物统一追加编号，也不要把年龄、职业编进昵称。
9. 不冒用现实人物，不写成真实用户投稿；这些人物始终是虚构示例。页面需保留示例内容说明。
10. 新增后运行 `git diff --check`、相关文件 ESLint、`npm run jianzhongsheng:check`、`npx tsc --noEmit` 和 `npm run ui:check`。只修改本地文件，不提交、不推送、不发布。
11. 新增或修改示例回应前，必须使用 `.agents/skills/jianzhongsheng-comment-voice/SKILL.md`。每篇为 0–3 条，数量必须打散，允许一篇完全没有回应。回应没有最低字数，可以只是很短的一句；只轻轻接住一个细节或顺手说一点自己的经历，允许口语、省略、没说完和不打句号。不要复述原文主旨、代替作者总结，也不要每句话都做出漂亮的哲理落点。
12. 禁止把“我多少岁”或“多少岁，发生了某事”当作手记与 `excerpt` 的默认开头。年龄只在对事件有实际叙事作用时，才能像其他信息一样自然出现在文中；优先从当下的动作、物件、对话或场景进入。同批内容还必须检查开头句式，不得让多个人物共用同一种自我介绍习惯。
