# 「今日见闻」内容规范

见天地 · 今日见闻栏目的写作与选题标准。修订于 2026-08-27。

体例是有出处的短事：每天一则，用一次对话、一个动作或一场遭遇，让读者原有的认识自然松动。可取佛家公案、道家寓言、人物轶事、工匠故事及世界各地的教诲故事。正文只讲故事，不替读者解释寓意。

## 一、每日形制

- 每天一则，不设「时、地、物」类目。
- 每次准备连续七天，存为一份周稿；`startDate` 是第一天，`stories` 依次对应之后七天。
- 每则包含一份经典原文和三至六段译文；译文 120–400 字，以 180–260 字为宜。
- 中文经典展示文言原文；外国经典展示原语言文本，不用中文转译冒充原文。
- 标题二至五字，是故事的「内涵题眼」：指出其核心冲突、认知转折或未说尽的余意，如「道不可言」「心不在马」。不要只摘取年龄、数量或器物，也不要写成说教口号。
- 页面显示简短出处，如「《庄子·天道》」；完整版本、页码与链接保存在 `sources`，供内部核查。
- 每则配置一张 360×136 的代码 SVG，文件名只使用日期：`public/daily-insights/YYYY-MM-DD.svg`。

## 二、文风

**先讲清楚。** 像向朋友复述一件旧事，交代人物、处境、动作和结果。古代官名、器物或地名影响理解时，用一句白话说明。

**译文停在转折处。** 最有分量的动作或一句话放在末段。不要补写「这个故事告诉我们」「由此可见」「这说明了」。

**不替古人作文。** 原文没有的心理、表情、景色和对话不要添。为了通顺可以转述，不把现代改写冒充原话。

**作者不出场。** 不写「我们」「值得深思」「今天依然如此」。反照由读者自己完成。

**不用机巧句式。** 不写刻意对仗、排比和「不是 X，而是 Y」式总结。正文的力量来自事件本身。

## 三、选题标准

每则至少满足四项：

1. **有动作**：人物必须做了什么，不能只是一段格言。
2. **有转折**：结尾改变了此前的理解、处境或关系。
3. **有余震**：触及学习、工作、判断、欲望、得失、生死或人与人的相处。
4. **能溯源**：能够指出具体古籍、篇章、卷次或可靠的近现代记录。

优先选用《庄子》《列子》《韩非子》《世说新语》《吕氏春秋》、禅宗灯录、普鲁塔克《希腊罗马名人传》、第欧根尼·拉尔修《名哲言行录》、鲁米《玛斯纳维》和《沙漠教父言行录》等有稳定文本的来源。

一周内应有变化：中外相间，技艺、识见、选择相间；避免连续七则都是师父训诫徒弟，或都以一句聪明话取胜。

## 四、出处与真实性

旧故事的价值首先来自文本，不一定来自可验证的历史现场。

- 寓言写成「《庄子》写过一件事」，不写成已被证实的史实。
- 轶事若记录年代晚于人物，应避免使用「确实」「亲口」等判断。
- 多个版本细节不同时，正文采用较早或较可靠的一版，差异记入 `sources`。
- 原文必须从可核查的底本转录，保留原语言的字母、变音符号与分行；节选时不得改写原句。
- 网文、短视频和无出处的名人名言不能作为来源。
- 「空杯」「苏格拉底把学生按进水里」等流传广但出处不稳的故事，查不到早期文本就不采用。

## 五、宗教与文化边界

- 可以讲宗教人物的行为与问答，不展开教义论证，不暗示某一信仰高于其他传统。
- 对不同文化只交代语境，不用现代标签替人物定性。
- 避开近现代政治史、民族争议和仅靠猎奇吸引人的惩罚故事。

```json
    {

```

发布前运行：

```sh
npm run insights:publish -- --file content/2026-08-27-week.json --dry-run
```
